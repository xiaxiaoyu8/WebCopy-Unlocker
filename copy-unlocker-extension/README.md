# Copy Unlocker · 网页复制解锁

Chrome / Edge Manifest V3 扩展。点击工具栏图标，尝试解除当前网页的复制、选择、剪切、粘贴和右键菜单限制。

## 使用场景

可用于尝试解除百度文库、CSDN、知乎等网站中已加载网页文本的复制与选择限制，方便摘录资料、整理笔记和复制代码。以上场景尚未逐站实测，实际效果取决于页面实现。付费或登录访问权限仍由网站控制，图片、扫描文档和 Canvas 文字需要其他提取方式。

## 安装与使用

1. 解压安装包，保留本文件所在目录。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的本目录。
4. 打开目标网页，点击插件图标。绿色图标表示解锁脚本已执行。
5. 刷新页面恢复原有行为，再次需要时点击启用。

## 权限与边界

仅申请 `activeTab` 和 `scripting` 权限。当前代码没有遥测或数据上传逻辑。

浏览器内部及受保护页面无法注入，跨域 iframe 与 Shadow DOM 内容可能仍受限。图片和 Canvas 文字需要其他提取方式。事件拦截可能影响网页编辑器、快捷键或拖动，出现异常时刷新页面。
